# DeepSeek V4.1 Flash: результаты полного прогона

Один выполненный ноутбук: `notebooks/deepseek_analysis.ipynb`. Получены все 344 ответа: 5 pilot, 39 задач A/B/C/D/F, по 100 строк E в режимах 0/5/20 примеров. Pilot исключены; 339 запросов основного эксперимента оцениваются раздельно по типам и режимам.

## Воспроизведение

`python -m pip install -r requirements-analysis.txt`

`python scripts/execute_deepseek_notebook.py`

Run All не обращается к API, не требует ключей и не исполняет код модели повторно. Исходный журнал — `results/models/deepseek/deepseek-v1/events.jsonl`. Полный снимок ID и контрольных сумм — `analysis/deepseek/snapshot.json`. Все C/D показаны с условиями, исходными ответами и обоснованиями. Для D сохранены код, stdout/stderr и совпадение метрик.

## Рассчитанные показатели

A/B/F: 24 правильных итоговых ответа из 24. На каждом типе 8/8. Bootstrap CI вырождается в [1; 1] на этой выборке; это не гарантия точности на новых задачах. Обоснования B проверяются отдельно.

D: все восемь исходных программ запустились без правок и совпали с эталонными численными метриками. Это не заменяет независимую проверку методологии.

| Режим DeepSeek | F1 класса 1 | Balanced accuracy | Допустимые предсказания | Незавершённые ответы |
|---|---:|---:|---:|---:|
| 0 примеров | 0.8065 | 0.7347 | 76/100 | 24/100 |
| 5 примеров | 0.7353 | 0.4966 | 51/100 | 49/100 |
| 20 примеров | 0.6545 | 0.3782 | 35/100 | 65/100 |

Всего 138 ответов классификации завершились статусом incomplete/max_output_tokens. Они входят в знаменатель как неуспех; повторные содержательные ответы не выбирались. Сравнения с LogisticRegression, GaussianNB и константой, интервалы и все предсказания сохранены в `analysis/deepseek/`.

Алгоритмические статусы по зарегистрированным критериям: H10 — reject; H12 — insufficient_data (часть 5-shot не определена, часть 20-shot поддерживает ожидаемое отставание). Первичная H5 остаётся сравнением YandexGPT и Qwen и находится в общем анализе команды. Прогнозы не менялись после получения ответов.

## Оставшаяся работа участников

Формы независимых проверок C/D — `analysis/deepseek/review/`. До их заполнения отсутствуют итоговая accuracy 39 задач и kappa. Предварительная техническая проверка не выдаётся за независимые оценки. Для настоящей слепой проверки организатор смешивает ответы разных моделей и не передаёт проверяющим ключ сопоставления.

Пять исходных случаев для самостоятельного разбора — `analysis/deepseek/error_examples.json`. При нулевых автоматических ошибках A/B/F это сохранённые незавершённые ответы классификации с usage и статусами сервера. Поля student_analysis, содержательные выводы и практические рекомендации команда заполняет самостоятельно по требованиям задания. Дополнительные ограничения: маленький банк, публичный датасет, один few-shot набор, различия режима рассуждений и провайдера.
