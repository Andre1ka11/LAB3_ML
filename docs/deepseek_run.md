# DeepSeek через Yandex Cloud

Рабочая ветка — `modelDeepSeek`. Модель — `deepseek-v4.1-flash` из Model Gallery Yandex AI Studio. Используются существующие `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` из локального `.env`; значение `YANDEX_MODEL` от старого прогона этот скрипт игнорирует.

## Последовательность

1. `python deepseek_runner.py` — проверка банка и 344 запросов без обращения к API.
2. `python deepseek_runner.py run --stage pilot` — пять отдельных пробных задач. Они не входят в итоговую оценку.
3. Проверить формат, usage и стоимость пилота. Ошибочные решения не переспросить. Основной прогон пока не запускать.
4. Записать параметры, прогнозы и критерии в `docs/deepseek_registration.json` и зафиксировать их коммитом до основного прогона.
5. `python deepseek_runner.py run --stage all` — продолжить тот же прогон: 39 задач A/B/C/D/F и 300 запросов E; пять сохранённых пилотных ответов пропускаются.
6. После завершения собрать анализ и один ноутбук DeepSeek. Для C/D сохраняется требование независимых оценок двух участников; автоматическая проверка кода их не заменяет.

## Одинаковые условия

Банк, русский язык, системная инструкция, порядок запросов, temperature=0 и лимит 4096 выходных токенов совпадают с прогоном YandexGPT. Поиск, инструменты и история диалога не используются. Режим рассуждений специально не задаётся: сохраняется режим сервиса по умолчанию; у разных моделей он может различаться. Запрошенные и возвращённые параметры сохраняются в журнале, поэтому одинаковый `temperature` не объявляется гарантией одинаковой работы моделей.

Обрабатывается только `user_prompt` и общая системная инструкция. Эталонные ответы и тестовые метки в API не передаются. Некорректные JSON и неверные ответы сохраняются как получены. Разрешается снять только внешнее Markdown-ограждение, с отдельной отметкой нарушения формата — как у остальных моделей.

## Расходы и восстановление

Тариф проверен 19.11.2026: 0,30 ₽ за 1000 входящих, 0,075 ₽ за 1000 кешированных входящих, 0,50 ₽ за 1000 исходящих токенов, включая НДС. Источник: https://aistudio.yandex.ru/ru/docs/ai-studio/pricing . Токены рассуждений повторно к `output_tokens` не прибавляются. Если детализация кеша отсутствует, расчёт консервативно использует полную входную цену. Это оценка по usage, фактический расход гранта проверяется в Billing.

Локальный предел: 300 ₽ на весь прогон, 10 ₽ на пилот. Перед каждым запросом резервируется стоимость консервативной верхней оценки; это не установленный в облаке лимит списаний.

Результаты: `results/models/deepseek/deepseek-v1/`. `events.jsonl` — исходный журнал с запросами и ответами API; `responses.jsonl` — восстанавливаемая таблица разобранных ответов; `config.json` — неизменные параметры. Ключ в них не записывается. `*.response.txt` — резервные копии сырых ответов для восстановления после сбоя.

`python deepseek_runner.py status` показывает завершённые запросы и оценку расходов, когда процесс не запущен. Повторный запуск с теми же параметрами пропускает сохранённые ответы. При сетевом обрыве скрипт останавливается: сервер мог обработать запрос. Не обходить остановку новым `run-id`; сначала проверить журнал и Billing, затем при необходимости явно разрешить один повтор командой `authorize-retry` с причиной.

## Гипотезы

Сохраняются H5/H10/H12. Первичное сравнение H5 — YandexGPT с локальной Qwen3 4B; DeepSeek не подменяет выбранную модель. H10 и H12 повторяются для DeepSeek по тем же критериям. Результаты YandexGPT и классических методов уже известны, поэтому это повторение эксперимента, а не регистрация, сделанная до просмотра любых результатов команды. Прогнозы для DeepSeek и параметры должны быть записаны до его основных запросов.

## Результат пилота — 19.11.2026

Получены 5 из 5 ответов, все со строгим JSON нужного формата. Сервер вернул точный URI выбранной модели и temperature=0. Использовано 1570 входящих и 863 исходящих токена; оценка стоимости с учётом кеша — 0,6721 ₽. Это проверка подключения и формата, а не итоговая оценка качества решений.

В ответах присутствуют токены рассуждений. Их глубина специально не задавалась, полный ответ API сохранён. Первый ответ восстановлен с диска после локальной ошибки чтения `content: null` в служебном блоке рассуждений; повторного обращения к модели не было.

Все 344 подготовленных запроса совпадают с запросами YandexGPT по текстам и параметрам, кроме URI модели. Основных ответов DeepSeek пока нет. Параметры, прогнозы, критерии и результат пилота записаны в `docs/deepseek_registration.json`; до запуска основного этапа этот файл требуется зафиксировать коммитом.

## Завершение прогона

Получены все 344 ответа; полный анализ — в `docs/deepseek_results.md` и `notebooks/deepseek_analysis.ipynb`. Бюджет был явно увеличен до 600 ₽, все изменения и сетевые повторы записаны в журнале. Сетевой транспорт использует 15 секунд на установку соединения и 360 секунд на ожидание ответа; параметры генерации не менялись. Новые запросы для просмотра отчёта не нужны.
