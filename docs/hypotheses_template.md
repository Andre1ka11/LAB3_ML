# Выбранные гипотезы: H5, H10, H12

Группы 2, 3 и 4 соответственно. До основного прогона Яндекса прогнозы и критерии записаны в docs/yandex_registration.json и зафиксированы коммитом ad4612f. Этот файл кратко излагает регистрацию; итоговые результаты находятся в ноутбуке и analysis/yandex/hypotheses.json.

Язык основного прогона — русский. H10 использует заранее выбранные 24 задачи A/B/F. Для H12 первичная метрика — F1 редкого класса, допуск не меньшего качества 0.05; сравнение на одинаковых 100 тестовых строках. Подробные критерии, bootstrap, интервалы и правила трёх исходов записаны в JSON регистрации.

Классические baseline были рассчитаны до регистрации; это раскрыто в протоколе. Пилот не включается в оценку. Для завершения H5 нужны ответы Qwen3 4B. Предварительная проверка B/C/D не является двумя независимыми оценками участников.
