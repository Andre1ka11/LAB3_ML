# Обзор репозитория перед локальным экспериментом

Проверены main, modelYandex и подготовленная ветка modelDeepSeek, PDF задания (ЛР3, страницы 1-9), банк, эталоны, запросы, разбиения, промпты, исходные журналы Yandex, анализ, ноутбук и тесты. Машинные JSON/JSONL/CSV прочитаны и проверены на разбираемость. Раздел AutoML относится к ЛР4 и в эту часть проекта не входит.

- main содержит общий банк, эталоны и baseline; modelYandex добавляет полный прогон и анализ. Новая modelLocalQwen создана от modelYandex, чтобы сохранить рабочий пример и провести заранее выбранное сравнение H5.
- 40 записей банка означают 39 обычных задач и протокол E01, разворачиваемый в 300 запросов. Pilot из пяти задач исключается. Нельзя считать 344 ответа единым знаменателем accuracy.
- В запросах нет эталонов, test labels и row_id; row_id используется только в журнале для парного сопоставления. Кодировка E обратна исходной sklearn, D08 оставляет исходную.
- Выбор H5/H10/H12 уже сделан командой. В регистрации Yandex для H5 заранее выбрана именно Qwen3 4B. Прогнозы для локальной модели взяты из командной регистрации, результаты Yandex и baseline уже известны.
- Общий parser снимает только внешнюю Markdown-оболочку. Он не исправляет JSON-арифметику, тип answer или код. Эти правила применены одинаково к обеим моделям.
- Ветвь DeepSeek на момент чтения содержит настройку и pilot; полных результатов там нет. Новая ветка не подменяет работу этого участника.
- Оценки C/D и обоснований B требуют двух независимых участников. Предварительная техническая проверка Codex не является двумя человеческими оценками. Общая accuracy 39 задач и kappa до заполнения форм остаются пустыми.
- H5 не изолирует эффект числа параметров: одновременно отличаются обучение, квантование, режим и провайдер. Доверительные интервалы на восьми задачах типа грубые; пары F зависимы.

В кэше Hugging Face найдены только GGUF gpt-oss-20b (F16, Q2_K, Q4_K_M, UD-Q4_K_XL). Они не соответствуют роли маленькой модели 3-8B. Для опыта скачаны официальные Qwen3-4B Q4_K_M, ревизия и SHA256 зафиксированы до генерации. Исходные модели пользователя не менялись.
