# GigaChat-2: рассчитанные результаты

Выполненный ноутбук: `notebooks/gigachat_analysis.ipynb`. Все показатели пересчитываются из сохранённых первых ответов, новых генераций при анализе нет.

Модель сервера: GigaChat-2:2.0.28.2. Всего 344 ответа: 5 pilot (исключены), 39 main, 300 E.

H10 signed gap: 0.4273; 95% cluster CI [0.2125; 0.6432]; coverage 22/24. ECE=0.4273.

В парных сравнениях 24 A/B/F задач ни одна из трёх доступных пар не имеет p_Holm<0.05; точные таблицы расхождений находятся в paired_comparisons.json. Это не утверждение эквивалентности качества.

D: первичный формат нарушен в 8/8 ответах, поэтому end-to-end pass@1=0. Вторичная диагностика точных подстрок без исправлений: 6/8 завершились без ошибки процесса; D02/D05 — NameError. Диагностика не изменяет первичную оценку. D01 использует accuracy под именем balanced_accuracy; численная близость к эталону не устраняет ошибку методологии.

Квота уменьшилась на 60822 токена; бесплатный кэш составил 256174 токенов. Эквивалент по опубликованному пакету Lite: 3.95343 руб.; фактических платежей 0 руб. Генерация заняла 252.09 с, без OAuth и подготовки окружения.
