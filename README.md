# ЛР 3: общий банк задач

## Локальная модель: Qwen3-4B

Ветка `modelLocalQwen`: выполненный ноутбук **`notebooks/local_analysis.ipynb`**, все 344 исходных ответа, метрики и графики в `analysis/local/`. Подробности запуска и оставшейся независимой проверки: **`docs/local_run.md`**. Обзор репозитория: `docs/repository_review.md`. Общие материалы и результаты Yandex сохранены.

## С чего начать

- **`TASKS.md`** — условия задач на русском и английском. Начните с него.
- **`TASKS_WITH_SOLUTIONS.md`** — правильные ответы, решения и критерии проверки. Нужен нам для оценки; модели его не отправляем.
- **`docs/protocol.md`** — общие правила эксперимента: как запускать запросы, сохранять ответы и считать результаты.

## Что нужно для запуска своей модели

- **`data/requests/bank_ru.jsonl`** — готовые запросы основного банка. Каждая строка — отдельное задание; модели передаём поле `user_prompt`.
- **`prompts/system_ru.txt`** — общая инструкция модели и формат ответа. Используем одинаковую для всех моделей.
- **`data/requests/pilot_ru.jsonl`** — пять задач для проверки подключения и формата. В итоговую оценку они не входят.
- Английские версии тех же файлов понадобятся, если выберем гипотезу про язык.

## Отдельно про классификацию — тип E

- **`data/classification/`** — одинаковые для всех обучающие примеры и тестовые строки. Разбиение самостоятельно не меняем.
- **`data/requests/classification_ru.jsonl`** — готовые запросы для 100 тестовых строк в режимах с 0, 5 и 20 примерами.
- **`data/classification/test_labels.csv`** — правильные тестовые метки, только для проверки. В запросы их не добавляем.

## Остальные файлы — вспомогательные

- **`data/tasks.jsonl` и `data/tasks.csv`** — тот же банк с эталонами в машинном формате. Целиком отправлять модели нельзя: внутри ответы.
- **`data/reference_code/`** — эталонные программы для задач на код.
- **`results/reference/`** — результаты эталонных программ и классических классификаторов. Это ещё не ответы наших LLM.
- **`requirements.txt`** — библиотеки для запуска эталонного кода.
- **`data/bank_manifest.json`** — контрольные суммы, чтобы проверить, что у всех одна версия материалов.


## Результаты YandexGPT

Один основной ноутбук: [notebooks/yandex_analysis.ipynb](notebooks/yandex_analysis.ipynb). В нём сохранены выполненные ячейки, графики, ответы C/D и предварительная проверка. Открывайте файл редактором Jupyter в VS Code; для пересчёта используйте Run All. Запросов к API при этом нет.

- [Инструкция по результатам](docs/yandex_results.md).
- [Запуск и продолжение эксперимента](docs/yandex_run.md).
- [Зарегистрированные прогнозы и критерии](docs/yandex_registration.json).
- `analysis/yandex/` — метрики, графики, исходный код D с stdout/stderr и формы проверки.
- `results/models/yandex/yandex-v1/` — первичный журнал, выгрузка ответов и параметры.

Установка зависимостей анализа: `python -m pip install -r requirements-analysis.txt`.

Предварительная проверка — одна оценка. Две независимые проверки и H5 по сравнению с Qwen пока не завершены; пустые значения не заменяются вымышленными результатами.

В source.citation выполнена редакционная правка. Её hashes и проверка неизменности содержательных полей записаны в data/metadata_cleanup.json; зарегистрированный manifest и отправленные запросы сохранены. В traceback скрыты абсолютные пути локальной среды, сообщения ошибок не менялись.
