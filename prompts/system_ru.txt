Верните ровно один JSON-объект без Markdown: {"answer": ..., "explanation": "краткое обоснование", "confidence": 0}. confidence - ваша уверенность в правильности ответа от 0 до 100. Для численной задачи answer - число; для верно/неверно - JSON boolean true/false; для выбора метода - строка; если данных недостаточно - строка "insufficient_data"; для генерации кода - строка с полным Python-кодом, содержащая переводы строк, без Markdown-ограждений; для классификации - целое 0 или 1. В кодовых задачах нельзя запускать код при генерации: только написать его. Не добавляйте ключи или текст за пределами JSON. Если вопрос явно просит долю от 0 до 1, используйте долю, а не число процентов.
